# 人生时间线

> 记录生活中的大小事情，留下时间的痕迹。

## 功能

- **时间线视图**：按时间倒序展示所有记录，一目了然
- **分类标签**：为每条记录打上标签，按主题筛选回顾
- **心情记录**：用 emoji 标注当天心情
- **全文搜索**：快速找到某段回忆
- **数据统计**：记录数量、年份分布、心情分布
- **数据导出**：随时备份为 JSON

## 快速开始

### 1. 安装依赖

```bash
cd life-timeline
npm install
```

### 2. 启动

```bash
npm start
```

启动后控制台会显示访问地址：
- **本机访问**：http://localhost:3000
- **局域网访问**：http://你的IP:3000（手机也能访问）

### 3. 使用

- 点击右上角 **「记录今天」** 添加新记录
- 左侧导航切换 **时间线 / 标签 / 统计** 视图
- 左侧标签云和年份筛选快速过滤
- 搜索框输入关键词全文搜索

## 数据存储

所有数据保存在同目录下的 `life.db`（SQLite 数据库）。

**备份方式**：
- 直接复制 `life.db` 文件
- 或通过 `/api/export` 导出 JSON

## 技术栈

- **后端**：Node.js + Express + SQLite3
- **前端**：原生 HTML/CSS/JavaScript（无框架依赖）
- **数据库**：SQLite（单文件，零配置）
